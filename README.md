# Recipe-Ai

This project is a tool for finding recipes when you have a random assortment of ingredients in your fridge and no idea what to cook. It uses the ChatGPT API to generate recipes, the Google Custom Search API to find related images, and the YouTube API to fetch tutorial videos. Simply input a list of ingredients, and the app will suggest delicious dishes you can make. As Auguste Gustav has said, anyone can cook!

![image](https://github.com/user-attachments/assets/d3a50a29-d29a-4211-b523-9e1ee78c6bda)

## How it works
1. **Input Ingredients:** Users enter a list of ingredients into a text box.
2. **Generate Recipes:** The app sends the input to the ChatGPT API, which generates a set of 3 recipes based on the ingredients.
3. **Fetch Media:** Images for the recipes are fetched using the Google Custom Search API. Video tutorials are sourced using the YouTube Data API.
4. **Display Results:** Recipes are displayed conveniently along with an image and a video tutorial for each dish.

## Technology used
**Backend:** 
- Node.js for API requests and handling logic.
- Axios for making HTTP requests.
  
**APIs:**
- ChatGPT API for recipe generation.
- Google Custom Search API for image retrieval.
- YouTube Data API for video retrieval.
  
**Frontend:**
- React for the user interface.
- CSS for styling components.

## Some limitations / work in progress
- The relevancy of the videos and images is random. While they have been configured to fetch media based on the exact recipe name, the behaviour may be unexpected in edge cases.
- The recipes generated by ChatGPT may need more finetuning to avoid impractical dishes.
- In the future, I should consider adding additional options for users to finetune their searches.
